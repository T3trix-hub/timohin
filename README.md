# Цімохін закуток — сайт-макет

Статический сайт (HTML, CSS, JS), без сборки: `index.html`, `menu.html`, `about.html`, `faq.html`, `contacts.html`.

## Запуск
Откройте `index.html` в браузере или `python3 -m http.server 8000`. Шрифты (Ruslan Display, PT Serif) и карта грузятся из интернета.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в корень все файлы папки.
2. Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
3. Сайт откроется на `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Что править
- **Меню и цены:** `menu.html`.
- **Изюминка «Табличка»** (главная, на фото входа): показывает по минскому времени, открыто ли кафе, и отсчёт до закрытия или открытия. Часы 11:00–23:00 заданы числами 660 и 1380 (минуты от полуночи) в блоке «Изюминка» в `main.js`; при смене графика поправьте их.
- **Контакты:** телефон, Viber, Instagram, Taplink прописаны в HTML (поиск по `145-50-45`, `t.z_malinayka`).
- **Карта:** `text=` в `<iframe>` на `contacts.html`.
- **Цвета и шрифты:** переменные в начале `style.css`.
